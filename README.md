# Disni Trophies — Design Studio

Phone app for the Disni Trophies shop: save trophy models with photo, size (mm) and price, measure sizes from a photo, design plates to the exact size with Malayalam/English fonts and voice input, remove photo backgrounds, export 300 dpi print files, and send designs with price on WhatsApp.

**Android app:** [Disni-Trophies.apk](../../releases/latest/download/Disni-Trophies.apk) — download, open, Install.

Each person signs in with their own email and password; data stays on their phone with an automatic backup in Download › Disni Trophies.
