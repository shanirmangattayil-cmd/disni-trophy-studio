Androidഈ phone

App download ചെയ്യൂ (APK)
  1. Download കഴിഞ്ഞ് file തുറക്കൂ → Install

iPhoneഈ phone

App തുറക്കൂ

  2. താഴെയുള്ള Share (□↑) ബട്ടൺ → Add to Home Screen
  3. Home screen-ൽ Disni icon വരും, app പോലെ തുറക്കാം
